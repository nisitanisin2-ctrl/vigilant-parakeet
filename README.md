# 菜園ノート

家庭菜園の栽培記録をつけるPWAアプリ（野菜管理アプリ）。

- 🌱 **畑**：植えた野菜を登録（種類・品種・場所・植付日・メモ）。植付からの日数、最後の水やり、収穫合計をひと目で確認
- 💧 **ワンタップ水やり**：一覧の💧ボタンで今日の水やりを記録。3日以上あいた野菜はオレンジで表示
- 📝 **作業記録**：水やり・追肥・収穫（数量と単位）・除草・病害虫・観察などを日付・メモ・写真つきで記録
- 📊 **集計**：年ごとの野菜別収穫回数と合計、作業回数、月別の収穫回数グラフ
- ⚙️ **バックアップ**：写真込みでJSONに保存・復元（データは端末のブラウザ内に保存）
- オフライン動作（Service Worker）・ホーム画面に追加して単独アプリとして使えます

GitHub Pages（Settings → Pages → main / root）を有効にすると
`https://nisitanisin2-ctrl.github.io/vigilant-parakeet/` で公開されます。

※ 以前の「写真メモ」アプリはGitのコミット履歴（v32）から復元できます。
