# 菜園ノート

家庭菜園の**育て方の予定**（種まき・追肥・収穫などの日）と、**水やり・収穫などの記録**をつけるアプリです。
表電卓の道具「🌱 野菜」の育成計画（33種類の野菜の予定・肥料・病気と害虫・育て方のコツ・地域の補正）と、
菜園ノートの記録（ワンタップ水やり・作業記録・収穫の集計）を、1つのアプリにまとめています。

**表電卓とは別のアプリ**です（manifest の `id` が別）。⚙ 設定の「アプリとして入れる」でホーム画面に入れると、表電卓とは別のアイコンで開き、データも別に残ります。オフラインでも動きます。
GitHub Pages（Settings → Pages → main / root）で `https://nisitanisin2-ctrl.github.io/vigilant-parakeet/` に公開されます。

## 使い方（下のタブ5つ）

| タブ | できること |
|---|---|
| 🌱 畑 | 「🗂 一覧／🗺 配置図」。上に「🌤 天気の注意」（霜・大雨など）と水やりのひとこと、「🗓 今月まけるもの」。上に「⚠️ 病気・害虫の注意報」（いま出やすい病気・虫と、どの野菜か。見出しで折りたためる）。育てている野菜の一覧（カードに、植えた日からの育ち具合の絵：8段階 種→芽→本葉→育つ→大きく→花→実→収穫）。上に「近いうちにやること」。💧 で今日の水やり、✏️ で記録。野菜を押すと、その野菜のカレンダー→育て方の予定（表）・肥料・コツ・病気・記録。育ち具合の絵は「✋ 合わせる」で実物に合わせられます |
| 📅 予定 | すべての野菜の予定を月のカレンダーで（⚙ 設定で場所を決めると16日先までの天気予報も。作業が始まる日に「🍅追肥」の札、時期が続く日に色の線、記録した日に絵）。左右になぞると月がかわります。上に「これから2週間にやること」。日を押すとその日の予定と記録 |
| 📝 記録 | 作業の記録の一覧・📷 写真（育ちのアルバム）・📊 集計（去年とのくらべ）・🧺 種・費用。右下の 🎤 で声でも記録 |
| 📖 育て方 | 33種類の野菜の、まく時期・予定・肥料・コツ・病気と害虫。「この内容で畑に登録する」で畑に入れられます |
| ⚙ 設定 | 家族と共有（共有ファイルを合わせる）、アドレスをQRコードで教える、見やすさ（シンプルモード：文字を大きく・出すものを少なく）、天気予報の場所（県・市町村の名前・今いる場所）、バージョン（🆕 新しくなったこと・🔄 更新をたしかめる）、アプリとして入れる（ホーム画面に追加）、畑ごとに管理する（畑を足す・畑ごとの地域）、住んでいる地域・標高・寒冷地（予定の日数の補正）、バックアップ、使い方 |

1. 「＋」で植えた野菜を登録します。野菜を選んで、種から／苗から と植えた日を入れると、予定日が出ます。
2. 予定の作業をしたら「✓ やった」。記録にも残ります（収穫は量を入れる窓が出ます）。
3. スマホやブラウザの「戻る」は、アプリの中で1つ前の画面に戻ります（窓→野菜の画面→畑の一覧）。畑の一覧でもう一度押すとアプリを閉じます。
4. 畑がいくつかあるときは、⚙ 設定の「畑ごとに管理する」を入れて「＋ 畑を足す」。開いたときは「すべての畑」が出ます。見出しの右の 📍 で畑を切りかえると、野菜・予定・記録がその畑のぶんだけになります（「すべての畑」でまとめて見られます）。地域も畑ごとに決められます。
5. はじめに ⚙ 設定 で地域を選ぶと、予定の日がその地域に合います（北海道なら日数が1.2倍など）。

予定の日数は家庭菜園のふつうの目安です。農薬は、ラベルで「使ってよい作物」と「収穫の何日前まで」を必ず確かめてください。

## ファイルのつくり

| ファイル | 中身 |
|---|---|
| `index.html` | 画面のかたち（見出し・中身の場所・＋ボタン・下のタブ）と、読みこむファイルの順番 |
| `css/style.css` | 見た目（色・カード・カレンダー・窓）。色は `:root` の変数で決め、ダークモードでも入れかわる |
| `js/version.js` | 版（APP_VERSION）と「新しくなったこと」（WHATSNEW） |
| `js/veg-data.js` | 野菜のデータだけ（予定の日数・地域・肥料・病気と害虫・コツ）。表電卓の「🌱 野菜」と同じ中身 |
| `js/util.js` | どこでも使う部品（日付・知らせ・窓・写真を小さくする） |
| `js/plan.js` | 予定の計算（植えた日＋日数×地域の倍率、つぎの作業、肥料の量） |
| `js/grow.js` | 育ち具合の絵（予定から、いまどこまで育ったかを決めて SVG で描く） |
| `js/sick.js` | 病気・害虫の注意報（出やすい月・とくに多い月・育ち具合の条件。地域でずらす） |
| `js/weather.js` | 天気予報（Open-Meteo から取る・3時間とっておく・カレンダーに出す・場所を選ぶ部品） |
| `js/qr.js` | QRコードを作る（表電卓と同じもの。設定の「アドレスをQRコードで教える」で使う） |
| `js/advice.js` | 天気の注意（霜・猛暑・大雨・強風）・水やりのひとこと・今月まけるもの |
| `js/myplan.js` | 自分の野菜・品種を足す窓（作業と日数・似ている野菜） |
| `js/export.js` | 書き出し：印刷（PDF）・画像・Excel（CSV）・スマホのカレンダー（.ics） |
| `js/fieldmap.js` | 畑の配置図（畝）と連作の注意（野菜の仲間と空けたい年数） |
| `js/records.js` | 写真アルバム・バックアップの声かけ・収穫の去年とのくらべ・自分の実績で予定を合わせる |
| `js/share.js` | 家族と共有（共有ファイルを合わせる）・種と資材と費用 |
| `js/voice.js` | 声で記録（話した言葉から野菜・作業・量・日を読みとる） |
| `js/store.js` | 保存（端末のブラウザの IndexedDB）とバックアップ、畑（fields）。前の菜園ノートのデータもそのまま読めます（地域は1つめの畑に入ります） |
| `js/app.js` | 5つのタブの画面と、野菜・記録を入れる窓 |
| `service-worker.js` | オフラインで動かすためのキャッシュ。新しい版は「いま更新」を押したときだけ入れ替わる |
| `manifest.json`・`icon-*.png` | ホーム画面に追加したときの名前とアイコン |
| `tests/run.js` | 自動テスト（`NODE_PATH=…playwright のある所 node tests/run.js`）。公開には使いません |

## 新しい版を出すとき

1. `js/version.js` の `APP_VERSION` を1つ上げ（v7 → v8）、`WHATSNEW` のいちばん上に変わったことを足す
2. `service-worker.js` の `CACHE` を `'saien-note-' + 同じ版` にする（テストで同じかたしかめます）
3. 使っている人には、下に「新しい版が用意できました」→「いま更新」で入れ替わり、開いたときに「v8 に新しくなりました」と出ます

天気予報は [Open-Meteo](https://open-meteo.com/)（登録・キー不要）から取ります。送るのは場所の緯度・経度だけです。

データはこの端末のブラウザの中だけに保存されます。機種変更などに備えて、⚙ 設定からときどきバックアップしてください。

※ 以前の「写真メモ」アプリは Git のコミット履歴（v32）から戻せます。
